# MangaReader

Настольное приложение для чтения манги на Rust (Rust + eframe/egui), с двумя источниками:

- **MangaDex** — поиск, популярное, главы, обложки, офлайн-загрузка глав
- **Локальные файлы** — CBZ/ZIP-архивы и папки с картинками (или папки с подпапками-главами)

## Возможности

- 📚 Библиотека с обложками и прогрессом чтения
- 🔍 Поиск по MangaDex (+ список популярного)
- 📖 Читалка: постранично / вертикальная лента / горизонтальная прокрутка
- ◄◄ RTL (справа налево, как в японской манге), режимы вписывания (вписать / по ширине / по высоте / 1:1)
- 🔍 Зум: Ctrl+колесо, клик по центру страницы = 2×, двойной клик — сброс
- ★ Закладки на страницы, история чтения
- ⬇ Скачивание глав MangaDex для офлайна
- 🌙 Тёмная тема, выбор языков глав (en/ru/...) и рейтинга контента

Всё состояние хранится в `~/.local/share/mangareader` (library.json, кэш обложек, скачанные главы).

## Горячие клавиши (в читалке)

| Клавиша | Действие |
|---|---|
| ← → | страница (учитывают RTL) |
| Space / Shift+Space | вперёд / назад |
| PgUp / PgDn | страница |
| Home / End | первая / последняя |
| + / − / 0 | зум / сброс |
| Esc | выход в библиотеку |

## Запуск

```sh
cargo run --release
```

Требуется Rust 1.80+.

## Структура

```
src/
  main.rs      — точка входа (eframe, glow-рендерер)
  app.rs       — состояние приложения, навигация
  ui.rs        — экраны: библиотека, поиск, деталь, история, настройки
  reader.rs    — читалка (3 режима, RTL, зум, прогресс)
  mangadex.rs  — клиент MangaDex API v5
  local.rs     — CBZ/папки, натуральная сортировка страниц
  library.rs   — персистентность (библиотека, закладки, история, настройки)
  images.rs    — кэш изображений с фоновой загрузкой и LRU-вытеснением
  downloads.rs — офлайн-загрузка глав (бережно к rate-limit)
  jobs.rs      — хелпер фоновых задач
  net.rs       — HTTP-клиент (ureq + rustls)
```
